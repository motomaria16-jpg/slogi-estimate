# SLOGI v70 — Анализ доступных помещений

## Что добавлено

- Новая отдельная страница `available-spaces.html` — «Анализ доступных помещений».
- Пункт меню: `Инструменты → Анализ → Анализ доступных помещений`.
- Фильтры поиска:
  - площадь помещения, от/до;
  - кластер;
  - этаж.
- Любой незаполненный фильтр не ограничивает выдачу. Если все фильтры пустые, выполняется общий поиск доступных коммерческих помещений.
- Вывод результатов:
  - источник (ЦИАН / Авито);
  - адрес;
  - кластер;
  - площадь;
  - этаж;
  - ссылка на исходное объявление.
- Кластер определяется существующей логикой проекта: координаты → полигоны кластеров; при отсутствии координат используется существующий геокодер.
- Поиск объявлений не записывает найденные позиции в текущую базу объектов и не меняет существующий workflow «Поиск помещений».

## Supabase

Добавлена новая Edge Function:

`supabase/functions/search-listings/index.ts`

Она работает рядом с уже существующими `import-listing` и `geocode-address` и использует тот же серверный принцип чтения ЦИАН/Авито: прямой серверный запрос, затем Browserless (если настроен), затем reader fallback.

В `supabase/config.toml` добавлено:

```toml
[functions.search-listings]
verify_jwt = false
```

## Существующие страницы

Существующая бизнес-логика страниц не изменялась. Изменены только общая навигация и `phase0-config.js`, чтобы зарегистрировать новую страницу и endpoint поиска.
