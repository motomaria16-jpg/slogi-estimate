# SLOGI v57 — импорт ЦИАН/Авито и автоопределение кластера

Дата: 12 августа 2026

## Что изменено

- Импорт объявлений теперь сначала канонизирует URL: технические query-параметры Avito (включая `context`) не передаются в reader/proxy, но исходная ссылка сохраняется в объекте.
- Добавлен структурированный запрос к Jina Reader (ReaderLM v2 + JSON schema) с обычным текстовым Reader и HTML-proxy как fallback.
- Парсер ЦИАН адаптирован под фактическую структуру присланного объявления: адрес из breadcrumb-строки, площадь, месячная аренда, высота потолков.
- Парсер Avito дополнительно извлекает площадь из slug URL даже при блокировке внешнего чтения страницы; при доступности текста/HTML извлекаются адрес, аренда, высота потолков и другие явно указанные поля.
- Улучшено распознавание JSON-LD/OpenGraph/embedded JSON.
- Если сайт блокирует внешнее чтение, UI показывает честный partial-import, а не сообщает об успешном полном импорте.
- После импорта адрес автоматически геокодируется через Яндекс и сразу используется для определения кластера.
- Геокодер генерирует несколько вариантов адреса, включая преобразования `с8` / `к8` в `строение 8` и `корпус 8`, что важно для московских адресов.
- При загрузке страницы существующие объекты без координат/кластера автоматически дообрабатываются.
- Кластер определяется по попаданию координаты в существующий GeoJSON; небольшой разрыв между полигонами обрабатывается через ближайшую границу.
- В сообщении после импорта отображается автоматически определённый кластер.

## Проверки

Локально проверен парсер на структуре присланного объявления ЦИАН:
- Москва, ул. Куусинена, 4К2;
- 60 м²;
- 85 000 ₽/мес.;
- высота потолка 2,45 м.

Проверена геометрия существующей сетки кластеров:
- координаты ул. Куусинена, 4к2 → кластер `ЦСКА`;
- район Волоколамского ш., 95/2 → кластер `Тушино`.

`node --check` проходит для `phase0-services.js` и `phase0-app.js`.

## Ограничение Avito

Avito может блокировать внешние автоматические запросы. Клиентская версия использует несколько reader/proxy fallback и URL-hints, но если сам Avito блокирует все внешние readers, стабильное получение всех полей потребует серверного `listingImport.endpoint` (он уже предусмотрен архитектурой). UI в этом случае не подставляет вымышленные значения.
