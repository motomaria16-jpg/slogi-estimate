# СЛОГИ v59 — Конкурентный анализ из Google Sheets

Источник подключён к книге:
`https://docs.google.com/spreadsheets/d/1y8EbNd8yTurIy5iWVjwsOYtfKgwgmTdV/`

Рабочий лист: **Свод**.

## Что сделано

- `CompetitiveAnalysisRepository` по умолчанию использует live Google Sheets.
- Система читает **все строки листа «Свод»**, поэтому текущие 30 кластеров и будущие добавленные кластеры появляются без изменения кода.
- Автоматическое обновление — каждые 5 минут, плюс кнопка «Обновить данные».
- Последняя успешная версия кешируется локально: при временной недоступности Google используется сохранённая версия.
- Добавлен основной путь чтения через Google Visualization CSV и fallback через Google Visualization JSONP, чтобы снизить риск CORS-ошибок.
- Колонки `Кластер`, `Рейтинг` и средняя стоимость/ставка аренды за 1 м² определяются автоматически по русским заголовкам. Если названия отличаются, вся таблица всё равно отображается, а mapping можно уточнить одной настройкой.
- Рейтинг и средняя аренда по кластеру автоматически используются в карточках объектов и сравнении объекта с кластером.
- После обновления таблицы существующие объекты пересчитываются без ручного редактирования каждой карточки.
- По кнопке «Конкурентный анализ» открывается крупная таблица внутри СЛОГИ. Показываются все непустые колонки исходного листа «Свод».
- Можно фильтровать таблицу по кластеру и открыть исходный Google Sheets в новой вкладке.
- Названия кластеров сопоставляются устойчивее: игнорируются слово «кластер», регистр и базовая пунктуация.

## Важно для доступа

Для браузерной live-синхронизации Google-файл должен разрешать чтение пользователям приложения. Самый простой вариант — доступ «Все, у кого есть ссылка: читатель». Если таблица должна оставаться закрытой, следующий шаг — читать её серверно через Supabase/Google service account.

## Что не захардкожено

- количество кластеров;
- список строк;
- дополнительные колонки листа «Свод»;
- значения рейтингов и ставок.

Поэтому при дополнении таблицы новыми кластерами новая информация автоматически появится в СЛОГИ.
