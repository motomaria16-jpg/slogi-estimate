# SLOGI v75 — диагностика поиска ЦИАН / Авито

## Исправлено
- Добавлена подробная диагностика `search-listings` в Supabase Logs по поисковым страницам и каждой карточке.
- Для Browserless Smart Scrape сохраняются стратегия, HTTP-статус, объём HTML/Markdown и найденные ссылки.
- Если Smart Scrape возвращает тонкую/заблокированную страницу, выполняется дополнительный запрос Browserless `/content` с полноценным браузерным рендерингом.
- В выдаче Browserless используются также готовые `links`, а не только regex по HTML.
- По каждой карточке логируется наличие распознанных адреса, площади, этажа и цены.
- Итоговый лог источника содержит `linksFound`, `cardsRequested`, `cardsSucceeded`, `addressesParsed`, `areasParsed`, `floorsParsed`, `pricesParsed`, `blocked`, `errors`.
- На странице добавлен диагностический блок вида: `25 ссылок → 25 карточек → 25 ответов → 0 адресов → 0 площадей`.
- Если адресов нет, геокодирование и определение кластеров полностью пропускаются.
- Геокодирование выполняется максимум по 3 адреса параллельно, до 9 секунд на адрес и с общим ограничением около 30 секунд.
- Поиск всегда выходит из loading-state через `finally`; частичные результаты сохраняются.
- При качестве распознавания адресов или площадей ниже 70% выводится предупреждение.

## Supabase
SQL v72 повторно выполнять не требуется.
Нужно только заменить код функции `search-listings` на `supabase/functions/search-listings/index.ts` из v75 и задеплоить её заново с текущей настройкой Verify JWT.
