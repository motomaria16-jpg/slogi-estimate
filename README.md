# СЛОГИ — система управления открытием объектов

Статическое веб-приложение для управления объектами СЛОГИ: от первичной оценки помещения до открытия и закрытия проекта. Сайт публикуется на GitHub Pages; данные и файлы могут синхронизироваться через Supabase.

## Два уровня навигации

### Вся сеть

Основное меню всегда содержит сводные разделы:

- **Объекты** — карта кластеров и карточки всех объектов;
- **Задачи** — поручения по всей сети;
- **Документы** — общий реестр файлов и версий;
- **Финансы** — бюджеты, обязательства и оплаты;
- **Подрядчики** — контрагенты, договоры и предложения;
- **Аналитика** — показатели сети и отклонения;
- **Ещё → Согласования** — решения и замечания;
- **Управление** — справочники, команда и настройки в зависимости от роли.

### Выбранный объект

Под главным меню постоянно находится отдельная строка **«Выбранный объект»**. В ней можно выбрать адрес и сразу открыть:

- обзор;
- этапы;
- документы;
- расчёты;
- коммерческое предложение;
- работы и сроки;
- финансы объекта;
- историю.

`passport.html` является единым рабочим пространством выбранного объекта.

## Понятные этапы открытия

1. **Первичная оценка объекта** — технические условия, критерии кластера и предварительная смета.
2. **Замеры и расчёт концепции** — замер, планировка, расчётная спецификация, точная смета, сроки и проект КП.
3. **Согласование условий аренды** — документы собственника, договор и протокол разногласий.
4. **Подготовка к ремонту** — заказные позиции, закупочная спецификация, подрядчики, Гант и график платежей.
5. **Ремонт и подготовка к открытию** — закупки, работы, поставки и электронный архив.
6. **Открытие и закрытие проекта** — приёмка, финальная стоимость, закрытие оплат и передача объекта в эксплуатацию.

Этап показывает положение объекта в процессе. **Статус хранится отдельно** и описывает текущее состояние: в работе, на согласовании, ожидает информации, приостановлен, просрочен и т. п.

## Расчётная цепочка

```text
Расчётная спецификация → Смета → Коммерческое предложение
```

- исходный Excel сохраняется без изменений;
- распознанные позиции можно проверить и отредактировать;
- смета создаётся по подтверждённой спецификации;
- КП формируется по данным паспорта и актуальной версии сметы;
- версии сохраняются, а устаревшие связанные документы помечаются;
- документы скачиваются в Excel, DOCX и PDF в зависимости от типа.

## Личный кабинет

В личном кабинете доступны:

- профиль и должность;
- системная роль, назначенная администратором;
- текущий объект;
- мои объекты;
- мои задачи;
- настройки уведомлений о задачах, согласованиях, сроках, платежах, документах и версиях;
- безопасность и смена пароля;
- управление командой только для администратора.

## Совместимость

`all-locations.html`, `measure-index.html` и `measure-passport.html` оставлены только как перенаправления на актуальные страницы. Старые дубли интерфейса не используются.

## Хранение данных

- объекты: `slogi_locations_v1`;
- задачи, согласования, финансы, версии, подрядчики, роли и журнал: `slogi_professional_state_v2`;
- файлы: IndexedDB локально и Supabase Storage после входа.

## Публикация

1. Распакуйте архив.
2. Полностью замените старые файлы репозитория содержимым архива.
3. Выполните `SUPABASE_SETUP.sql` в Supabase SQL Editor.
4. Включите GitHub Pages для ветки `main`, папка `/ (root)`.
5. Разрешите домен GitHub Pages в настройках ключа Яндекс Карт.
6. После публикации нажмите `Ctrl + F5`.

Подробные инструкции находятся в `PUBLISH_ON_GITHUB.md`.
