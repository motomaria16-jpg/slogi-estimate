# СЛОГИ — система работы с объектами

Статический сайт для GitHub Pages с облачной синхронизацией через Supabase.

## Основные страницы

- `index.html` — карта и список объектов;
- `passport.html` — паспорт объекта, документы, диаграмма Ганта и график платежей;
- `specification.html` — формирование и редактирование сметы;
- `proposal.html` — коммерческое предложение;
- `all-locations.html` — совместимая копия главной страницы.

## Облачная синхронизация

В `cloud-sync.js` уже внесены Project URL и Publishable key проекта Supabase. Сайт поддерживает:

- вход по электронной почте и паролю;
- одинаковые адреса и данные объектов на компьютере и телефоне;
- закрытое хранение документов в Supabase Storage;
- автоматический перенос существующих данных из браузера при первом входе;
- локальную копию для работы при кратковременной потере связи.

Перед первым использованием выполните `SUPABASE_SETUP.sql` по инструкции `SUPABASE_SETUP.md`.

## Публикация на GitHub Pages

1. Загрузите всё содержимое папки в корень репозитория.
2. Убедитесь, что `index.html` находится в корне.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
5. Сохраните настройки.

Подробный порядок приведён в `PUBLISH_ON_GITHUB.md`.

## Мобильная версия

`mobile-fixes.css` исправляет отображение кнопок, карточек, таблиц, паспорта, сметы и КП на узких экранах. Интерфейс входа Supabase также адаптирован для телефона.

## Обновление сайта

После загрузки новой версии выполните принудительное обновление:

- Windows: `Ctrl + F5`;
- macOS: `Command + Shift + R`;
- телефон: закройте старую вкладку и откройте сайт заново.
