# СЛОГИ — система работы с объектами

Статический сайт, готовый к публикации через **GitHub Pages**.

## Основные страницы

- `index.html` — главная страница «Все объекты»: карта и список объектов;
- `passport.html` — паспорт объекта, документы, диаграмма Ганта и график платежей;
- `specification.html` — формирование и редактирование сметы;
- `proposal.html` — коммерческое предложение;
- `all-locations.html` — совместимая копия главной страницы.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое этой папки в корень репозитория**. Файл `index.html` должен находиться в корне, а не во вложенной папке.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`;
   - Branch: `main`;
   - Folder: `/ (root)`.
5. Нажмите **Save** и откройте адрес, который покажет GitHub Pages.

## Яндекс Карты

Ключ JavaScript API Яндекс Карт находится в `yandex-map-config.js`. После публикации добавьте домен GitHub Pages в список разрешённых HTTP Referer в кабинете Яндекс Карт, например:

```text
https://USERNAME.github.io/*
https://USERNAME.github.io/REPOSITORY/*
```

Для статического сайта ключ используется в браузере и технически виден посетителям, поэтому обязательно ограничьте его разрешёнными доменами.

## Хранение данных

На GitHub Pages данные сохраняются локально в браузере пользователя. Они не синхронизируются автоматически между разными компьютерами и браузерами. Файл `cloud-sync.js` и `server.py` оставлены как заготовка для дальнейшего подключения общей базы данных.

## Локальная проверка

На Windows запустите `START_SITE.bat`, затем откройте:

```text
http://localhost:8000/
```

Для работы карты на локальном адресе временно разрешите `localhost` в настройках ключа Яндекс Карт.

## Обновление сайта

После загрузки новой версии выполните принудительное обновление страницы:

- Windows: `Ctrl + F5`;
- macOS: `Command + Shift + R`.
