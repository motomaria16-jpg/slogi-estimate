# СЛОГИ — пересборка карты, паспорта и документов

## Главная страница

- Яндекс Карта запускается автоматически сразу после открытия страницы.
- На карту одновременно наносятся 58 полигонов кластеров из `clusters.geojson`.
- Справа от карты всегда отображаются карточки объектов.
- Режимы «Таблица» и «Канбан» удалены.
- Нажатие на полигон кластера очищает остальные фильтры, приближает карту и показывает все объекты выбранного кластера.
- Поиск, фильтр кластера и фильтр статуса работают совместно.
- Карточки объектов остаются доступны даже при ошибке внешнего API карты.

## Единая шапка

`professional-shell.js` теперь заново собирает одну и ту же шапку на всех рабочих страницах. Логотип, название страницы, личный кабинет, основное меню, поиск и уведомления находятся в единой оболочке.

## Паспорт объекта

Старая смешанная структура удалена. Новый паспорт состоит из пяти вкладок:

1. Обзор и основные параметры.
2. Документы.
3. Работы и сроки.
4. Финансы.
5. История.

В паспорте доступны:

- единая карточка объекта;
- статусы и реквизиты;
- документная цепочка «Спецификация → Смета → КП»;
- загрузка и замена плана;
- скачивание каждого документа;
- компактная диаграмма Ганта без процента готовности;
- редактируемые даты и продолжительность в днях;
- график платежей;
- история версий;
- скачивание всех файлов объекта одним ZIP-архивом.

## Спецификация

Добавлена новая страница `source-specification.html`.

- исходный Excel сохраняется отдельно;
- приложенная спецификация включена как `Specification_template.xlsx`;
- шаблон можно применить одним нажатием;
- программа распознаёт параметры, разделы, подразделы, позиции, цены, количества и формулы;
- все строки редактируются;
- можно добавлять и удалять позиции;
- отредактированная спецификация скачивается в Excel;
- сохраняются версии;
- при изменении спецификации смета помечается как устаревшая.

## Смета

Страница `specification.html` полностью пересобрана.

- смета создаётся из сохранённой спецификации;
- старые элементы загрузки плана и КП со страницы удалены;
- редактируются наименование, тип, цена, количество и стоимость;
- доступны входные параметры, высота потолков и резерв;
- рассчитываются мебель, отделка, работа, демонтаж/стены и общий итог;
- поддерживаются черновик и версии;
- при изменении сметы КП помечается как устаревшее;
- скачивается полноценный XLSX и сохраняется в паспорте.

## Коммерческое предложение

Страница `proposal.html` построена по приложенному двухстраничному Word-шаблону.

- сохранены фирменная структура, логотип, заголовки, таблицы и колонтитулы;
- объект, площадь, адрес, сроки и контактные данные подставляются автоматически;
- весь текст редактируется непосредственно на страницах предпросмотра;
- КП связывается с выбранной версией сметы;
- поддерживаются черновик и версии;
- DOCX создаётся на базе настоящего Word-шаблона, а не HTML-файла с расширением `.doc`;
- доступны DOCX и PDF;
- файлы сохраняются в паспорте объекта.

## Публикация

1. Распаковать архив.
2. Полностью заменить файлы в корне репозитория GitHub Pages.
3. Дождаться завершения Actions / Pages deployment.
4. Выполнить `Ctrl + F5`.
5. Проверить разрешённый домен для ключа Яндекс Карт.

Существующие объекты из `slogi_locations_v1` остаются совместимыми. Старые поля `model`, `state`, `proposalHtml`, `gantt` и `paymentSchedule` используются как резервный источник при первом открытии новой версии.
