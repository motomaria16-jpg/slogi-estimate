# Конкурентный анализ — ручная загрузка

1. Откройте «Поиск помещений» → «Конкурентный анализ».
2. Нажмите «Загрузить XLSX» (после первой загрузки — «Заменить файл»).
3. Выберите актуальный Excel-файл конкурентного анализа.
4. Программа всегда читает лист `Свод` целиком:
   - все используемые колонки от первой до последней;
   - обе строки заголовков исходного файла;
   - все строки, где заполнена колонка `Кластер`.
5. Для объекта используются:
   - кластер — колонка `Кластер`;
   - стоимость 1 м² — колонка `м2 семейный аренда`;
   - рейтинг — крайняя правая колонка `Рейтинг(население важнее)`.

При обновлении исходной таблицы просто загрузите новую версию файла. Количество строк может увеличиваться — код менять не нужно.
