# Публикация SLOGI на GitHub Pages и подключение Supabase

## 1. Настройте базу Supabase

1. Откройте проект Supabase.
2. Перейдите в **SQL Editor → New query**.
3. Скопируйте туда содержимое `SUPABASE_SETUP.sql`.
4. Нажмите **Run** и убедитесь, что выполнение завершилось без ошибки.

## 2. Настройте адрес сайта в Supabase Auth

Откройте **Authentication → URL Configuration**.

**Site URL:**

```text
https://motomaria16-jpg.github.io/slogi-estimate/
```

**Redirect URLs:**

```text
https://motomaria16-jpg.github.io/slogi-estimate/**
```

Сохраните настройки.

## 3. Загрузите файлы на GitHub

1. В репозитории откройте **Add file → Upload files**.
2. Загрузите всё содержимое архива с заменой существующих файлов.
3. Файл `index.html` должен находиться непосредственно в корне репозитория.
4. Не загружайте ZIP как единственный файл: GitHub Pages его не распакует.

## 4. Включите GitHub Pages

В **Settings → Pages** установите:

- Source — `Deploy from a branch`;
- Branch — `main`;
- Folder — `/ (root)`.

Нажмите **Save**.

## 5. Разрешите домен для Яндекс Карт

В настройках JavaScript API Яндекс Карт добавьте HTTP Referer:

```text
motomaria16-jpg.github.io
```

## 6. Перенесите существующие данные

1. Сначала откройте опубликованный сайт на компьютере, где уже сохранены адреса.
2. Разверните **«Личный кабинет»** в шапке сайта.
3. Создайте аккаунт или войдите.
4. Дождитесь сообщения о синхронизации данных.
5. При необходимости заполните ФИО и должность.
6. Откройте сайт на телефоне и войдите под тем же аккаунтом.

При включённом подтверждении почты сначала подтвердите электронную почту по ссылке из письма Supabase.

## 7. Проверьте работу

Проверьте:

- отображение сохранённых адресов на компьютере и телефоне;
- сохранение паспорта объекта;
- сохранение сметы и КП;
- загрузку и скачивание документов;
- отображение карты;
- мобильные кнопки и карточки.
