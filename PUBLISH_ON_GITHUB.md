# Публикация профессиональной версии СЛОГИ

## 1. Обновите Supabase

1. Откройте **Supabase → SQL Editor → New query**.
2. Выполните файл `SUPABASE_SETUP.sql` целиком.
3. Убедитесь, что запрос завершился без ошибки.

Это обязательный шаг для синхронизации задач, финансов, согласований, версий, команды и справочников.

## 2. Проверьте настройки авторизации

В **Authentication → URL Configuration** укажите адрес опубликованного сайта.

Пример:

```text
Site URL: https://motomaria16-jpg.github.io/slogi-estimate/
Redirect URL: https://motomaria16-jpg.github.io/slogi-estimate/**
```

## 3. Загрузите сайт

1. Распакуйте архив.
2. В репозитории выберите **Add file → Upload files**.
3. Загрузите содержимое распакованной папки, а не сам ZIP.
4. Для полной замены удобнее клонировать репозиторий через GitHub Desktop, удалить старые файлы из локальной папки и скопировать содержимое нового архива.
5. Не загружайте ZIP как единственный файл: GitHub Pages использует распакованные HTML, CSS и JavaScript.
6. Убедитесь, что `index.html` находится в корне репозитория.

## 4. Включите GitHub Pages

В **Settings → Pages** установите:

- Source — `Deploy from a branch`;
- Branch — `main`;
- Folder — `/ (root)`.

## 5. Настройте Яндекс Карты

В настройках ключа JavaScript API добавьте разрешённый HTTP Referer:

```text
https://USERNAME.github.io/*
https://USERNAME.github.io/REPOSITORY/*
```

## 6. Обновите кэш

После завершения публикации откройте сайт и выполните:

- Windows — `Ctrl + F5`;
- macOS — `Command + Shift + R`.

## 7. Проверьте основные сценарии

- вход в личный кабинет;
- карта кластеров и карточки объектов;
- выбор объекта в постоянной строке шапки и открытие паспорта;
- прохождение вкладки «Этапы»;
- изменение статуса и ответственного;
- создание задачи;
- загрузка версии документа;
- согласование документа;
- добавление платежа и договора;
- справочник цен и версия сметы;
- аналитика;
- мобильное меню;
- синхронизация на втором устройстве.

## 8. Резервная копия

Перед заменой действующей версии рекомендуется открыть **Настройки → Резервное копирование → Скачать JSON**. При необходимости файл можно импортировать обратно через тот же раздел.
