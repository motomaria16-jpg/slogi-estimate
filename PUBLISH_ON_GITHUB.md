# Как опубликовать сайт

## 1. Создание репозитория

На GitHub нажмите **New repository**, задайте название и создайте репозиторий. Для закрытого проекта можно выбрать Private, но доступность GitHub Pages зависит от тарифа и настроек аккаунта.

## 2. Загрузка файлов

Откройте репозиторий и выберите **Add file → Upload files**. Загрузите все файлы из этой папки так, чтобы `index.html` находился непосредственно в корне репозитория.

Не загружайте сам архив как единственный файл: GitHub Pages не распаковывает ZIP автоматически.

## 3. Включение GitHub Pages

Откройте **Settings → Pages** и установите:

- Source — `Deploy from a branch`;
- Branch — `main`;
- Folder — `/ (root)`.

Сохраните настройки. Ссылка на опубликованный сайт появится на этой же странице.

## 4. Подключение карты

В настройках ключа JavaScript API Яндекс Карт добавьте опубликованный домен в разрешённые HTTP Referer. Без этого карта может не загрузиться.

## 5. Проверка

Проверьте страницы:

- `/index.html`
- `/passport.html`
- `/specification.html`
- `/proposal.html`

Создайте тестовый объект, сохраните паспорт, откройте смету и коммерческое предложение. Данные теста сохранятся только в текущем браузере.
