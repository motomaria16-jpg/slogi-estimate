# SLOGI v65 — карточка объекта по утверждённому референсу

- Карточка потенциального помещения перестроена по утверждённому макету: компактная верхняя сводка, кластер и рейтинг справа, строка источник/объявление/статус, 6 одинаковых метрик, двухколоночный блок проверки и готовности, 3 нижние карточки Планировка/Замер/Решение.
- Блок «Параметры кластера» перенесён в нижнюю панель действий, как в референсе.
- Удаление объекта сохранено как ненавязчивое действие внутри блока «Решение».
- Отдельная полоса сравнения со средним кластером скрыта в карточке для соответствия референсу; расчёт и данные сохранены и продолжают использоваться в списке/конкурентном анализе.
- В колонке «Рейтинг» списка теперь показывается только одно число рейтинга. Убраны знак №, круглый бейдж и отдельный порядковый номер строки.
- В карточке рейтинг показывается в виде «★ N» в верхнем блоке.
- Бизнес-логика, ручной импорт конкурентного XLSX, геокодирование, кластеры, статусы и переход к смете не изменялись.
