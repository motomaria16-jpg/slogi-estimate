# Визуальный референс платформы

Основной визуальный источник платформы — [макет «Слоги онлайн-платформа. Дизайн.» в Figma](https://www.figma.com/design/BJ5SCaHBA2rgclEuw3NTt2/%D0%A1%D0%BB%D0%BE%D0%B3%D0%B8-%D0%BE%D0%BD%D0%BB%D0%B0%D0%B9%D0%BD-%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D0%B0.-%D0%94%D0%B8%D0%B7%D0%B0%D0%B9%D0%BD.-SHOW?node-id=1463-39448).

Текущая страница «Поиск помещений» (`available-spaces.html`) является реализованным локальным эталоном дизайн-токенов: шрифта, цветов, поверхностей, границ, радиусов, отступов и состояний элементов. Новые интерфейсы должны переиспользовать эти токены и не вводить параллельную дизайн-систему.
