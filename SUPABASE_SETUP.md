# Подключение Supabase к сайту SLOGI

Проект и публичный ключ уже внесены в `cloud-sync.js`.

## 1. Создайте таблицы и закрытое хранилище

1. Откройте проект Supabase `slogi-estimate`.
2. В левом меню выберите **SQL Editor**.
3. Нажмите **New query**.
4. Откройте файл `SUPABASE_SETUP.sql`, скопируйте его содержимое целиком и вставьте в редактор.
5. Нажмите **Run**.
6. Должно появиться сообщение об успешном выполнении без ошибок.

Скрипт создаёт:

- таблицу `slogi_user_state` для адресов, паспортов, смет и КП;
- таблицу `slogi_attachments` для сведений о файлах;
- закрытый Storage bucket `slogi-files`;
- Row Level Security, чтобы пользователь видел только собственные данные.

## 2. Настройте адрес сайта для писем подтверждения

В Supabase откройте **Authentication → URL Configuration**.

Укажите:

**Site URL**

```text
https://motomaria16-jpg.github.io/slogi-estimate/
```

В **Redirect URLs** добавьте:

```text
https://motomaria16-jpg.github.io/slogi-estimate/**
```

Сохраните настройки.

## 3. Опубликуйте новую версию сайта

Загрузите в корень репозитория GitHub всё содержимое архива с заменой прежних файлов. Особенно важны:

- `cloud-sync.js`;
- `SUPABASE_SETUP.sql`;
- все HTML-файлы с обновлённой ссылкой на `cloud-sync.js?v=10`.

## 4. Первый вход и перенос данных

1. Сначала откройте сайт на компьютере, где уже сохранены адреса.
2. Нажмите кнопку **«Облако: войти»** в правом нижнем углу.
3. Создайте аккаунт или войдите.
4. После входа локальные адреса и файлы будут перенесены в Supabase.
5. Затем откройте сайт на телефоне и войдите под той же электронной почтой и паролем.

При включённом подтверждении электронной почты сначала перейдите по ссылке из письма Supabase.

## Как работает синхронизация

- изменения адресов, паспортов, смет и КП отправляются в облако автоматически;
- файлы сохраняются и загружаются через закрытое хранилище Supabase;
- при первом входе существующие локальные данные переносятся в облако;
- на новом устройстве облачные данные загружаются после входа;
- локальная копия остаётся рабочей при кратковременной потере связи.
