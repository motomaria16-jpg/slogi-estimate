# SLOGI v74 — устойчивый анализ доступных помещений

- Парсер карточек ЦИАН/Авито сначала читает JSON-LD и встроенные JSON-состояния, затем meta/HTML, затем текстовые fallback-паттерны.
- Browserless используется в приоритетном режиме и для карточек, а не только для страниц поиска.
- Неудачный повторный парсинг больше не затирает ранее сохранённые адрес, площадь, этаж, координаты и кластер в Supabase.
- Геокодирование не запускается для объявлений без адреса.
- Геокодирование идёт максимум в 3 параллельных потока, с таймаутом 9 секунд на адрес и общим лимитом 30 секунд.
- Контроль качества источника предупреждает, если распознано менее 70% адресов или площадей.
- Поиск всегда выходит из состояния загрузки; частичные результаты остаются доступными.
- Повторный SQL не требуется. Нужно обновить только Edge Function search-listings и файлы сайта.
