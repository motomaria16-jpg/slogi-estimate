# СЛОГИ — изменения v55

- Кластер автоматически определяется по адресу через Яндекс Геокодер и существующие полигоны кластеров.
- Для объектов без координат выполняется аккуратное автоматическое дозаполнение координат/кластера после загрузки карты.
- Таблица объектов занимает всю ширину страницы; карта перенесена ниже таблицы.
- В таблице одновременно видна область примерно на 10 строк; при большем количестве доступен внутренний скролл и кнопка «Развернуть все».
- Статус объекта меняется прямо в таблице. Для «Не подошло» причина обязательна.
- «Следующее действие» остаётся вычисляемым из готовности объекта и открывает его карточку.
- Убрано legacy-пространство над шапкой на desktop: шапка фиксирована у верхнего края.
- Импорт ЦИАН/Авито: сохранён приоритет собственного backend endpoint; если он не настроен/ошибается, включён best-effort fallback через Jina Reader и последующее геокодирование адреса.
