# СЛОГИ v56 — Поиск помещений

## Исправлено

- Статусы в таблице получили пять разных визуальных состояний: серый, оранжевый, синий, зелёный и красный.
- Панель поиска и фильтров стала компактной и выровнена как в утверждённом визуальном референсе; строка поиска больше не растягивается на свободную ширину.
- Поиск выполняется по адресу и комментарию.
- Таблица ограничена примерно 10 строками; при большем количестве объектов появляется внутренний scroll и кнопка «Развернуть все».
- Автоматическое определение кластера усилено: Яндекс Геокодер проверяет несколько вариантов адреса и несколько результатов, предпочитает координату, попадающую в существующий кластер. Для небольших разрывов между полигонами используется ближайшая граница кластера.
- При сохранении объект дополнительно получает кластер по координатам на уровне Phase0Service, даже если UI не успел заполнить название кластера.
- Для ранее сохранённых объектов без координат/кластера backfill теперь проходит по всем объектам, а не только по первым пяти.
- Импорт ЦИАН/Авито теперь последовательно пробует настроенный backend endpoint и несколько reader/proxy-стратегий, умеет разбирать как текстовую версию страницы, так и HTML/JSON-LD/OpenGraph. Расширено распознавание адреса, площади, месячной аренды, высоты потолков, количества окон и координат.

## Важно про ЦИАН/Авито

Платформа остаётся статическим сайтом GitHub Pages. ЦИАН и Авито могут блокировать внешнее чтение конкретного объявления (anti-bot/CORS). В v56 добавлены несколько автоматических способов чтения и fallback, но 100% гарантии для любой ссылки без собственного серверного импортера дать невозможно. Архитектура существующего `listingImport.endpoint` сохранена: при подключении собственного backend он используется первым.
