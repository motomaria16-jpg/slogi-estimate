# Исправление главной страницы — 27.07.2026

## Исправлено

- Устранён двойной вертикальный отступ между шапкой и основной навигацией.
- Главная страница больше не запускает Яндекс Карты и геокодирование сразу после открытия.
- Удалено одновременное выполнение старого и нового рендеринга главной страницы.
- Убраны наблюдатели DOM, которые повторно обрабатывали карточки объектов.
- Оптимизирована первичная подготовка профессиональных данных: все объекты обрабатываются одним сохранением вместо последовательной записи для каждого объекта.
- Карта переведена в ленивый режим и загружается только по кнопке пользователя.
- Определение отсутствующих координат выполняется отдельно и последовательно.

## Новая структура главной

- компактный заголовок портфеля;
- четыре KPI без перекрытия меню;
- компактный блок событий, требующих внимания;
- быстрые действия;
- единый раздел объектов;
- поиск и фильтры;
- представления: таблица, карточки, канбан и карта;
- адаптивные карточки для телефона.

## Проверено

- отсутствие ошибок JavaScript в новой главной странице;
- прокрутка страницы;
- переключение всех четырёх представлений;
- поиск по адресу;
- фильтрация;
- отображение объектов на настольном экране и телефоне;
- отсутствие горизонтальной прокрутки на ширине 390 px;
- корректная последовательность: шапка → меню → содержимое.
