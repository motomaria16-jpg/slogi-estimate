# SLOGI v64 — ручной конкурентный анализ

- Полностью отключено чтение конкурентного анализа из Google Sheets/облака.
- Добавлена ручная загрузка XLSX из окна «Конкурентный анализ».
- Всегда читается лист «Свод».
- Читаются все используемые колонки листа от первой до последней и все строки с кластером; при добавлении новых строк они подхватываются автоматически при следующей загрузке файла.
- В таблице отображаются обе реальные строки заголовков (группы из строки 11 и детальные названия из строки 12) с учетом объединённых ячеек.
- Кластер определяется по колонке «Кластер».
- Стоимость 1 м² для сравнения берется из «м2 семейный аренда».
- Рейтинг берется из крайней правой колонки «Рейтинг(население важнее)».
- После загрузки данные кэшируются локально и сразу пересчитывают рейтинг/сравнение у объектов.
