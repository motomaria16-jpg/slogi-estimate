# Исправление зависания и компоновки на всех страницах

Дата: 27.07.2026

## Что было причиной

На разных страницах одновременно работали несколько несовместимых слоёв интерфейса: старая фиксированная шапка, новая навигация, локальные стили страниц и облачная синхронизация. Из-за этого появлялись двойные верхние отступы, наложения элементов и повторные перерисовки. Облачный модуль также начинал синхронизацию и перенос вложений сразу после открытия страницы, а паспорт объекта автоматически запускал геокодирование адреса.

## Что исправлено во всём проекте

- создана единая оболочка `app-shell.css` для всех 16 HTML-страниц;
- шапка и основная навигация объединены в один sticky-блок;
- убран искусственный верхний отступ и конфликт fixed/sticky-позиционирования;
- личный кабинет всегда остаётся компактным элементом шапки;
- скрытые панели и модальные окна больше не перехватывают прокрутку и нажатия;
- установлена единая ширина контента и одинаковые боковые отступы;
- исправлено поведение шапки, меню и кабинета на планшетах и телефонах;
- все общие JavaScript-файлы перенесены из `<head>` в конец страницы;
- локальные данные выводятся до запуска облачной синхронизации;
- запуск Supabase отложен до завершения первого отображения страницы;
- удалена автоматическая перезагрузка страницы после получения облачных данных;
- миграция вложений выполняется в фоновом режиме и не чаще одного раза за сеанс;
- удалено автоматическое создание демонстрационных задач, рисков и согласований;
- события изменения данных объединяются через `requestAnimationFrame`, чтобы исключить каскадные перерисовки;
- карта портфеля загружается только по команде пользователя;
- геокодирование адреса в паспорте больше не запускается при обычном открытии страницы;
- исправлен разбор JavaScript на странице коммерческого предложения;
- старые страницы `all-locations.html` и `measure-index.html` заменены облегчённым портфелем;
- версии CSS и JavaScript обновлены для принудительного сброса кэша GitHub Pages.

## Проверка сборки

- проверено 16 HTML-страниц;
- все внешние JavaScript-файлы прошли `node --check`;
- проверено 8 встроенных JavaScript-блоков;
- скриптов, блокирующих разбор в `<head>`, не осталось;
- отсутствующие локальные ссылки и файлы не обнаружены;
- дублирующиеся реальные HTML `id` не обнаружены;
- проверен баланс CSS-блоков;
- архив проверен на целостность.

## Публикация

Замените содержимое репозитория файлами из нового архива. Файл `index.html` должен находиться в корне репозитория. После завершения GitHub Actions откройте сайт с жёстким обновлением `Ctrl + F5`.
