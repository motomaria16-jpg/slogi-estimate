# Обновление search-listings — SLOGI v74

SQL повторно выполнять НЕ нужно: таблицы из SUPABASE_MARKET_ANALYSIS_V72.sql подходят для v74.

1. Откройте Supabase → Edge Functions → search-listings.
2. Откройте редактор кода функции.
3. В архиве v74 откройте `supabase/functions/search-listings/index.ts`.
4. Скопируйте файл целиком и полностью замените старый код функции.
5. Нажмите Deploy / Save and deploy.
6. Убедитесь, что секрет `BROWSERLESS_TOKEN` по-прежнему задан.
7. Обновите файлы сайта на v74.
8. Откройте «Анализ доступных помещений» и сначала запустите поиск без фильтров.

В v74 низкое качество распознавания (<70% адресов или площадей) показывается предупреждением. Объявления без адреса не отправляются в геокодер, поэтому поиск не должен зависать на определении кластеров.
