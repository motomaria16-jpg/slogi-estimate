# SLOGI v73 — исправление поиска доступных помещений

- Кнопка `Найти объявления` перенесена в видимую область блока `Критерии поиска`.
- Исправлено перекрытие заголовка страницы фиксированной шапкой/навигацией.
- Текст состояний приведён к действию `Найти объявления`.
- Клиентский таймаут поиска уменьшен до 90 секунд с понятным сообщением об ошибке.
- По умолчанию первичный проход: 2 страницы выдачи и до 25 объявлений на источник вместо 5/100.
- ЦИАН и Авито обрабатываются параллельно в Edge Function.
- Страницы выдачи внутри одного источника также запрашиваются параллельно.
- Добавлены индивидуальные таймауты внешних запросов (direct / Browserless / reader), чтобы Edge Function не зависала надолго.
- Browserless Smart Scrape запрашивает html + markdown + links.
- SQL-схему v72 повторно выполнять не требуется.
- Edge Function `search-listings` необходимо заново Deploy после замены `supabase/functions/search-listings/index.ts`.
