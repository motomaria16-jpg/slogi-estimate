# Единые логотип и типографика

Эталоном оформления выбрана страница «Объекты».

## Исправлено

- На 14 рабочих страницах подключён единый файл `objects-visual-standard.css` последним в каскаде.
- Логотип в шапке везде имеет одинаковые пять букв, размеры, цвета, скругление, интервалы и положение буквы «И».
- Названия страниц в шапке имеют одинаковую гарнитуру, размер, насыщенность, регистр и межбуквенный интервал.
- Подзаголовки в шапке унифицированы.
- Интерфейс сайта приведён к одной системной гарнитуре, используемой на странице «Объекты».
- Поля, кнопки, меню, статусы, строка выбранного объекта и личный кабинет используют одну гарнитуру.
- Внутренняя типографика предпросмотра коммерческого предложения сохранена по фирменному Word-шаблону.
- На телефонах сохраняется полный пятибуквенный логотип, вместо удаления части букв на узких экранах.
- Обновлены номера версий CSS и оболочки для сброса кэша GitHub Pages.

## Проверено

- Все 14 рабочих HTML-страниц содержат одинаковую структуру логотипа `СЛОГИ`.
- Единый стилевой файл подключён последним на каждой странице.
- Отсутствующие локальные ссылки не обнаружены.
- Синтаксис всех JavaScript-файлов проверен.
