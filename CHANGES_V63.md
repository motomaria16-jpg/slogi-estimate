# СЛОГИ v63 — исправление «Конкурентного анализа»

## Что исправлено

- Заголовки таблицы берутся из фактической рабочей строки заголовков листа «Свод», а не создаются из merged-групп с автоматическим forward-fill.
- Убраны искусственные названия вида «Кластер (3)», «Кластер (4)», «Показатель 5» для реально подписанных столбцов.
- Рейтинг теперь жёстко сопоставлен с бизнес-колонкой **«РЕЙТИНГ(Население важнее)»** — крайней правой рейтинговой колонкой листа «Свод».
- Стоимость кластера для сравнения с помещением берётся из колонки **«м2 семейный аренда»**.
- Кластер сопоставляется по колонке **«Кластер»**.
- Старый кеш конкурентного анализа v62 автоматически игнорируется, чтобы неверные старые сопоставления не продолжали попадать в карточки.
- После нового обновления Google Sheets рейтинг и ставка кластера снова применяются ко всем объектам через существующий `Phase0Service`.
- Поскольку рейтинг в «Свод» — это место в рейтинге (1 = лучший), сортировка объектов изменена на **«Рейтинг — лучший сначала»**.
- В карточке объекта рейтинг показывается как **№1, №2, …**, а не как условный балл со звездой.
- В таблице конкурентного анализа закреплены первые две колонки `№` и `Кластер` для удобной горизонтальной прокрутки.

## Источник данных

Google Sheets: лист «Свод», gid `846752535`.

Ключевые поля v63:

- `Кластер` → имя кластера;
- `м2 семейный аренда` → ставка аренды кластера за 1 м²;
- `РЕЙТИНГ(Население важнее)` → рейтинг кластера.
